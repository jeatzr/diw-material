Modo oscuro fácil

Esta página cambia sola según el tema de tu sistema. No tiene JavaScript ni botón.

¿Cómo probarlo?

Cambia el tema claro u oscuro de tu dispositivo, o usa las DevTools del navegador (Emulate CSS prefers-color-scheme). 

@media (prefers-color-scheme: dark) {
  :root {
    --color-fondo: var(--color-tinta-900, #14213d);
  }
}
